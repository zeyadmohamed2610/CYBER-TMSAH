# استعادة كلمة المرور

المسار الوحيد: «نسيت كلمة المرور» في شاشة الدخول → بريد الحساب → رسالة استعادة من `cybertmsah@gmail.com` → رابط Supabase Auth مؤقت للاستخدام مرة واحدة → كلمة مرور جديدة وتأكيدها → تسجيل الدخول مجددًا.

لا توجد طلبات استعادة يدوية أو أرقام واتساب أو موافقات إدارية. لا تتغير كلمة المرور عند طلب الرسالة، ولا تكشف رسالة القبول وجود الحساب. واجهة الإرسال تمنع الطلبات المتزامنة وتنتظر دقيقة بين المحاولات؛ حد المزود يظل مطبقًا على الخادم.

## إعداد البريد في Supabase

- SMTP host: `smtp.gmail.com`، port: `587`.
- SMTP user وsender address: `cybertmsah@gmail.com`.
- Sender name: `CYBER TMSAH`.
- كلمة المرور: Google App Password بعد تفعيل التحقق بخطوتين، وتُحفظ في إعدادات SMTP الخاصة بـSupabase فقط.
- قالب recovery: [recovery.html](../supabase/templates/recovery.html)، بعنوان «استعادة كلمة المرور | CYBER TMSAH».
- رابط الزر يستخدم `{{ .ConfirmationURL }}` الصادر من Supabase؛ لا يُنشأ توكن أو كلمة مرور في واجهة المستخدم.
- يجب السماح بمسار `/reset-password` للنطاقات المدعومة في Auth Redirect URLs. مدة الصلاحية من إعدادات Supabase Auth.

بعد تحديث كلمة المرور، تُلغى جلسات التجديد ويُطلب تسجيل الدخول مجددًا. رابط غير صالح أو مستخدم لا يفتح النموذج؛ وجود جلسة عادية مخزنة لا يكفي لفتحه.

يتحقق النموذج من حساب جلسة الاستعادة عند فتحه وقبل الحفظ، ويرفض تحديث حساب مختلف إذا تغيّرت الجلسة. يرفض Supabase كلمة المرور الحالية بخطأ `same_password`؛ تظهر رسالة عربية بجوار الحقل، وتظل الجلسة والنموذج متاحين لإدخال كلمة مرور مختلفة. أخطاء التحقق أو انقطاع الاتصال لا تؤدي إلى تسجيل الخروج؛ يحدث تسجيل الخروج بعد نجاح التغيير فقط.

قالب البريد يستخدم جداول عرض وخصائص تنسيق مضمّنة لدعم برامج البريد، مع شعار الهوية الجديدة وزر واضح ورابط بديل وتنبيه الخصوصية. لا يحتوي على أدوات تتبع أو سكربتات أو رمز استعادة منشأ محليًا.

تغيير كلمة مرور حساب Gmail يلغي كلمات مرور التطبيقات، ويحتاج تحديث إعداد SMTP. لا توضع أسرار SMTP أو مفاتيح الإدارة في الواجهة أو المستودع.

المراجع: [Supabase SMTP](https://supabase.com/docs/guides/auth/auth-smtp)، [Google App Passwords](https://support.google.com/accounts/answer/185833).
